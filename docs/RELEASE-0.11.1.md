# 星枢用户中心 0.11.1

- 首页概览分别显示现有用户、现有购买用户，按账号去重，另标注历史付费和状态待同步人数。现有购买用户按仍有效的已付服务计算，过期、远端删除/停用及本地账户停用不计入；仅当月流量耗尽仍计入。直接数据库聚合，避免管理列表分页截断。
- 系统设置增加“套餐说明”：标题、正文可手动修改，支持换行、预览及恢复默认。游客首页、用户套餐页、管理员预览共用已保存文案，可见套餐页下一次定时刷新生效。
- 说明以纯文本呈现并校验长度，沿用主管理员权限、CSRF、设置版本冲突检查及审计；旧配置自动使用默认文案，无额外数据库迁移。
- 概览统计卡片适配电脑与手机，保留原有订单、订阅、支付、配额、主题及媒体功能。
- 新增数据库口径、权限、说明持久化/校验及界面回归测试。
