# 星枢用户中心 0.12.0

- 背景加载增加超时、最多两次自动重试、失败底色回退和旧图保留；手机与电脑只加载当前视口对应背景。页面数据轮询不重新请求背景，不向第三方 URL 拼接随机参数。外观设置显示加载状态并可手动重试；外链不受上传的 1 MiB 限制。第三方图片源仍取决于其可用性，需要稳定展示可上传图片。
- 电脑侧栏可收起、恢复并保存个人选择；手机改用隐藏式侧边菜单，支持遮罩、Escape、点选自动收起、滚动恢复与键盘焦点处理，所有原有功能保持可达。
- 优惠码和邀请码显示剩余次数、占用及已验证/待付款数量，可按页查看使用者、时间、订单和状态。优惠码使用口径与结算一致，待付款预占、取消释放、退款不返次数；邀请码区分预占、验证和释放。
- 使用记录直接查询已有业务账本，每页 25 条，不复制额外日志；新增邀请记录查询索引，权限仍按 coupons / invitations 分别隔离。
- 六类客户端教程增加官方下载安装入口，完善平台选择、远程订阅导入、更新、权限、排错与隐私说明。旧编辑内容保留，仅补缺失的已知客户端下载地址；管理员可载入新版推荐到草稿并自行保存，下载地址也可编辑。
- 包含数据库迁移、权限/次数口径/分页/旧教程兼容及图片重试/响应式导航的回归测试。
