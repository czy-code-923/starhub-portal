# 星枢用户中心 0.7.0

- 恢复简洁的订阅导入布局，客户端格式使用下拉框，自动切换当前订阅链接和专属二维码；不提供配置下载。
- 套餐卡片显示实时销售余量，页面可见时每 10 秒刷新。新购待付款订单预占库存，取消释放；创建订单事务锁复核防超卖。续费不占新购名额或独立身份容量。
- 新增原订阅续费：在订阅与设备选择服务、周期、优惠码并付款，后台或 Telegram 核款后延长原到期时间。未到期从原日期追加，已到期从现在起算，原链接和身份保留。
- 续费只延长期限，不清零用量、不改流量配额、协议、倍率、设备权限或重置日；删除、停用或撤销的身份不能通过续费重建。订单幂等与服务绑定校验防重复发放及跨用户操作。
- 要求星枢控制面 0.25.1+。新增真实 PostgreSQL 库存、付款审核、原身份续期测试及前端下拉和续费流程验证。
