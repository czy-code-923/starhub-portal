# 星枢用户中心 0.6.0

- 每个订单分别展示客户端订阅入口，可按客户端查找并单独查看、复制链接和显示二维码；移除配置文件下载，旧 content 接口返回 410。
- 星枢端身份删除、停用、过期和流量耗尽同步至购买用户、订单与容量页。完整分页快照每分钟验证，获取链接前实时复核；网络故障与权限错误不会被视为删除，已删除身份不会自动重建。
- 容量页区分星枢现存身份上限、已核验订单数、有效与失效服务；修正历史映射无条件计数。
- 操作日志及已完成任务自动按 30 天与条数双重限制保留，主管理员可手动清理。保护未完成任务、付款与幂等开通凭据。
- 修整管理员列表、权限编辑和移动端布局，防止操作按钮撑开信息列。
- 新增隔离 PostgreSQL 回归验证与前端链接归属、格式隔离、失效状态及清理确认测试。更新继续使用 SHA-256 校验、备份与失败恢复。
