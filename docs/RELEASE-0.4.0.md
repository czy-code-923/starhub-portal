# 星枢用户中心 0.4.0

- 一单一服务：每个新订单使用独立代理身份、额度、设备限制和订阅，同套餐多次购买可以分别查看、复制、下载配置和显示二维码。服务列表每页 25 条，仅加载当前订单的实时用量，页面可见时每 30 秒刷新。
- 旧权益迁移：将未到期合并权益拆成原购买订单。控制面在单个事务中分配按比例扩容的剩余流量，保留原合并到期、重置时间，撤销旧用户和所有旧链接；控制面与购买端分别持久化迁移结果和幂等请求。节点完成身份同步后旧配置失效，旧用户须刷新新链接。
- 原有套餐及有效权益按同数字 GiB 扩容，20 GiB 在 Clash 常用口径显示 20 G。套餐仍保留 GB/GiB 选项，后台计费倍率不再出现在客户目录。
- 口令红包无需填写流水号：人工或 Telegram 二次确认实际领取及金额后开通，系统生成内部核账编号；静态收款码仍必须核验真实流水。机器人新增订单按钮和短编号查询，新增审批权限需单独授予并绑定有核款权限的有效管理员，一次性确认 5 分钟内有效。
- 修复配置下载为错误文档的问题；下载检查 HTTP 状态，按订单及客户端获取实际文件。提供 Android/iOS/Windows/macOS/Linux 官方客户端入口与原创导入教程。
- 套餐信息按“名称＋内容”逐条编辑与增删；公告支持多条置顶及顺序，适配移动端换行。
- 版本页展示应用/数据库资源、磁盘可用量与实现身份上限。本版要求星枢 0.25.0+，同机受限助手可请求现有星枢官方更新器完成兼容更新；外部控制面须先升级。

验证包括 PostgreSQL 业务/升级测试、Go race/vet、前端交互与生产构建、安装器与反代安全测试、Linux Docker 实际安装/回滚/卸载及 IPv6 入口检查。支付与 Telegram 验证均使用隔离数据和模拟 API，不代表已替你领取真实红包或审核真实订单。
