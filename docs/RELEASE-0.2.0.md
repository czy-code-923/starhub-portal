# 星枢用户中心 0.2.0

支持可反复查看的邀请码与优惠码、支付宝/微信个人静态收款码及人工核款。付款截图不自动发放权益；需核对准确金额、真实流水及到账时间，防重复核销与越权读取凭证。

新增直接邮箱验证注册、两次密码确认、个人资料和密码维护、主管理员与按功能授权的副管理员。新增 3 类 6 个可编辑的模拟套餐（默认不可下单），保留原有官方支付宝接入、商业独立身份、配额、订阅、域名及可回滚更新。

升级自动迁移现有管理员为主管理员，保留账号、配置和订单。旧版仅哈希保存的邀请码不能还原，需显式重新生成。未上传真实收款码、未配置 SMTP 时对应入口保持未启用。

验证覆盖 PostgreSQL 业务状态、旧版迁移、支付幂等/权限/私有图像、前端交互、真实 Docker 安装与失败回滚。无真实商户转账或邮件发送测试。
