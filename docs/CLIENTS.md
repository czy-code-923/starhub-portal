# 默认客户端教程来源

2026-11-10 核对官方入口；下载链接使用官方发布页/商店页，避免硬编码某个版本或架构的安装包。

- [FlClash 官方项目](https://github.com/chen08209/FlClash) 与 [官方下载](https://github.com/chen08209/FlClash/releases/latest)：对应 Android / Windows / macOS / Linux，远程配置使用 Mihomo 格式。
- [Clash Verge Rev 安装](https://www.clashverge.dev/install.html) 与 [订阅导入](https://www.clashverge.dev/guide/profile.html)：桌面使用 Mihomo 远程订阅；本教程保留证书验证，遇到证书问题联系管理员修复。
- [sing-box 图形客户端](https://sing-box.sagernet.org/clients/) 分别提供 [Android](https://sing-box.sagernet.org/clients/android/) 和 [Apple 平台](https://sing-box.sagernet.org/clients/apple/) 入口；远程配置与裸节点 URI 不同，使用面板对应格式和专属二维码。
- [Hiddify 官方客户端入口](https://hiddify.com/app/)：使用面板 Hiddify.app 专属配置，不强制改用自动识别。
- [v2rayNG 官方项目](https://github.com/2dust/v2rayNG) 与 [官方下载](https://github.com/2dust/v2rayNG/releases/latest)：Android 远程订阅分组使用对应 URI 订阅格式，具体支持协议以安装版本与控制面兼容目录为准。
- [Shadowrocket App Store](https://apps.apple.com/app/shadowrocket/id932747118)：iOS 节点订阅选择 Subscribe，完整配置导入另行区分；地区及费用由商店决定。

默认教程在 `internal/portal/content/client_help.json`。管理员可以维护自定义内容及下载地址；程序不会覆盖已保存步骤。选择新版默认模板只是编辑草稿，保存后才对用户生效。页面中的链接与二维码包含用户订阅凭据，教程要求用户避免公开；本站不提供用户配置下载。
