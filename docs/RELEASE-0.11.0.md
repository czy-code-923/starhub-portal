# 星枢用户中心 0.11.0

- 修复“未登录可查看套餐”：开启直接进入套餐首页，点击购买再登录，登录后接回选中的套餐；关闭仍显示登录页。购买与支付 API 继续执行原有身份、价格与名额校验。
- 工单创建和回复、公告支持上传图片、缩略图和放大查看；每条最多 6 张，每张 PNG/JPEG 至多 1 MiB。工单图片仅本人及具有支持权限的管理员可读取。
- 新增“外观与主题”页：薄荷、晴空蓝、玫瑰、深夜四种主题；站点默认与浏览器个人选择分离，电脑和手机背景独立设置，支持上传、HTTPS 图片地址及安全的 url(...) 输入。
- 手机套餐采用紧凑双列，极窄屏自动单列，详情展开查看；管理员菜单分类折叠，系统设置按入口、注册、星枢连接、邮件和官方支付分栏。
- 图片独立存储并按引用读取，保留原有只读应用容器和数据库备份；每用户 64 MiB、全站 512 MiB 图片上限，未引用上传 24 小时后回收，后台每 5 分钟检查。
- 包含数据库迁移、媒体 API、权限与浏览器流程回归测试。不会改变现有订单、支付核验、协议授权、配额、UUID 或订阅链接。
