# 星枢用户中心 0.14.0

- 手机导航移到顶部，采用紧凑工具行＋横向滑动栏目，完整菜单、主题、刷新保留。选中栏目自动进入可见区域；下滑收起、上滑恢复，兼容安全区、键盘导航和减少动态效果设置。
- 订单与开通采用响应式行/卡片，按钮独立排列；容量统计分项展示，长资源描述自动换行；后台任务和操作记录分离对象、状态、时间与详情，避免宽度溢出；补齐失败权限同步任务的重试入口。
- 优惠码增加普通、限时循环、永久循环。循环优惠按独立订阅绑定，仅首次领取占次数，后续同订阅续费不重复计次；领取期限与续费优惠期限分开，支持停用、适用范围和减免封顶。
- 续费自动核验绑定优惠，支持手动换码；报价后金额变化返回冲突并要求重新核价，避免未经确认按更高金额创建订单。已创建订单、付款与历史权益保留快照。
- 管理 API、OpenAPI、优惠使用记录同步扩展。迁移 016 为旧优惠默认普通模式，升级时自动执行。
- 本地 PostgreSQL 完整 Go 测试、Go vet、49 项前端测试及生产构建通过；正式发布须再通过 CI 并发检查与真实 Docker 安装、升级、回滚、卸载验证。

升级前自动备份数据库；启动验证失败由更新器恢复。管理员可在“版本与更新”检查升级，也可运行 `python3 /opt/starhub-portal/scripts/manage.py update --version 0.14.0`。本次不修改星枢控制面的节点或用户权限。
