# 星枢用户中心 0.13.0

- 延续 0.12.1 的宽屏居中修复和手机底栏。手机以紧凑底部栏目栏为默认：向下滚动收起、向上滚动出现，页首/页尾、编辑表单、菜单和弹窗操作时保持可用；减少动态效果偏好下不自动隐藏。监听采用被动事件与帧合并，无轮询。
- 手机边缘使用响应式触控留白及设备安全区，适配圆角、曲面与平直屏幕布局；没有按机型硬编码。真实硬件观感仍受系统浏览器安全区报告影响。
- 用户与审核重排为自适应网格，长邮箱换行、用户 ID 展开查看，操作区不挤压；新增当前列表搜索和每页 25 条展示，保留现有审核、停用、删除及恢复权限。
- 增加主管理员“历史清理”：按记录及按时间批量预览，每批最多 100 条，确认后只处理预览 ID，并在事务内重查状态。
- 已关闭工单、停用公告及其不再引用的图片可永久删除；无付款、核款、开通、续费或任务关联的已取消过期订单可永久删除。仍有待处理通知或关联账本的订单受保护。
- 付费失效订单与已结束核款可归档并恢复显示；归档核款的图片、收款码快照及已使用口令可单独永久清理。保留流水唯一性、红包防重哈希、订单、开通和续费凭据，不改变用户订阅或发放次数。
- 操作日志和完成任务继续沿用限量限时清理。历史数据主要占磁盘；删除后 PostgreSQL 可复用空间，不自动执行阻塞业务的 VACUUM FULL。
- 新增数据库迁移、清理安全边界与预览范围测试、滚动收放及用户界面回归测试。
