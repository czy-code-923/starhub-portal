# 星枢用户中心 0.9.0

- 套餐用户组、协议变更自动同步到已购订阅；原凭据、链接、有效期、流量配额、已用量及购买金额保持。权限独立版本、持久化任务、自动及手动重试，阻止旧任务覆盖新配置。
- 使用套餐当前有效独立订阅人数作为名额。有效期内续费不重复占用，过期或删除释放；新购、过期后重新开通需有空位，待付款预占，取消释放，按原身份去重避免续费重复计数。
- 流量耗尽但未到期仍持有身份名额；远端状态不完整时保守计数，写入前强制读取完整快照并在数据库事务中核验，避免超卖。
- 保留到期后不足 72 小时的续费窗口。已删除身份通过新购开通新身份，不恢复旧 UUID。期限内实际到账可稍后审核。
- 管理端显示有效人数占用和权限同步状态；客户端权限未同步时明确提示等待，区分真正不兼容的客户端。客户端刷新原订阅即可获取最新节点权限。
- 新订单开通使用当前套餐节点权限，财务字段仍按购买快照。报价事务复用同一数据库连接读取目标与更新状态，避免小连接池被等待锁的请求耗尽。
- 补充真实 PostgreSQL 过期/删除释放、满额正常续费、过期重新开通竞争、权限同步与不改购买快照测试，以及用户端人数规则界面测试。

需要星枢控制面 0.25.2+；同机更新助手自动请求兼容更新。迁移 012 自动执行，并为已有正式套餐安排权限同步，无需重新创建购买用户或有效订阅。
