# 星枢用户中心 0.3.0

新增支付宝口令红包人工核验：加密绑定订单，拒绝跨订单重复口令，受限查看与审计，普通列表和通知不泄露口令；只有管理员确认实际到账后才排队开通。保留支付宝官方在线支付、支付宝及微信个人静态码。

新增主管理员管理的 Telegram 接入、按数字用户 ID 分配权限、只通知或独立查询命令模式、私聊核验、持久化通知队列、按接收人确认与失败重试。不会接管原后台的轮询或已有 Webhook，不自动领取红包或审核付款。

修复域名绑定：与同机星枢已就绪证书和对应反代关联，校验实际站点安装 ID；增加域名重试入口，IP 访问独立保留。安装命令支持自动探测 / 指定 IPv4、IPv6、端口和监听范围，不绑定固定 VPS。

验证包括真实 PostgreSQL 隔离业务测试、Telegram 模拟服务权限及重试测试、前端交互测试、安装器安全检查和 CI 中的实际 Docker 安装、升级回滚及卸载测试。未代用户进行真实付款、红包领取、邮件或 Telegram 消息发送测试。
