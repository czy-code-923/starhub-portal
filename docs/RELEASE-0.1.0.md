# 星枢用户中心 0.1.0

初始购买面板：独立管理员和用户权限、邀请 / 白名单注册、邮箱验证与人工审核、分类 / 推荐套餐、优惠码、官方支付宝签名流程、幂等订单与持久化权益开通、流量额度、客户端订阅 / 二维码、设备访问、公告和工单。

需要星枢 0.24.0 商业接口。商业套餐只允许可计费独立协议身份，原自用与共享订阅保持原行为。每安装独立密钥，生产无演示套餐和通用管理员令牌。

提供 Linux / Windows Docker Desktop 安装入口、两种架构运行包、完整源码、保留数据卸载、独立数据清除与管理员恢复命令。可不绑定域名，后台可选独立域名并检查 / 更新本站版本。

启用邮件、真实支付及售卖套餐需要站点管理员配置 SMTP、支付宝商户和可计费用户组；本版本不代填商户密钥，也不使用假支付。超时支付退款、跨套餐变更和推广系统留待后续。
