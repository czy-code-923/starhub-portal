# 星枢用户中心 0.8.0

- 套餐协议按实际勾选及所选用户组提供的可计费协议显示；切换分组清理不适用的协议，示例套餐不再预填 AnyTLS / Hysteria2。保存及下单实时核验全部选择，公共目录不宣称不可用协议。
- 管理员可删除套餐并恢复为下架状态；用户可移除失效、删除订阅的显示记录，并从已移除列表恢复。原服务、订单、付款和名额账本保留，有效订阅或待处理续费不可误删。
- 原订阅在未到期或到期后不足 72 小时内可下单并付款续费；超过期限禁止续费。每个新购和续费订单均占同套餐 1 个销售名额，待付款预留，取消释放，数据库事务锁防并发超卖。
- 续费截止同步至报价、订单、客户端界面、手动收款、Telegram 审批及支付宝回调。期限内实际付款可等待稍后核验；迟到回调只进入人工核账，不自动开通。已核验的历史权益不追溯更改。
- 续费沿用原身份和链接，仅延长期限，保留额度、用量、月重置日、设备和协议权限；冻结开通参数与原服务绑定校验，避免重试改变目标。
- 增加 PostgreSQL 生命周期、所有权、72 小时边界及续费/新购竞争同一库存的测试，以及协议选择、确认删除和恢复界面测试。桌面与移动端管理操作保持对齐。

要求星枢控制面 0.25.1+。迁移 011 自动执行，更新前自动备份数据库；无需重新创建用户或订阅。
