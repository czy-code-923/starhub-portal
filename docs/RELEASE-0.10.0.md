# 星枢用户中心 0.10.0

- 自动检查订阅时不再将购买面板的 Go HTTP 客户端当作用户代理客户端。配合星枢 0.25.4 修复仅 AnyTLS 等配置无 URI 时错误阻止自动链接显示；明确不支持的客户端仍拒绝。
- 新增 `manage.py domain-enable --domain buy.example.com` 和 `domain-disable --allow-http`。使用受限本机助手令牌、类型化 API、任务队列和现有入口，不接受命令或 SQL；禁用域名后回到安装时记录的 IP＋端口，不写死 IP。
- 命令检查现有更新/网关任务、HTTP 明确选择、官方支付 HTTPS 回调、回环部署限制和域名格式。保留后台其他设置、密钥和订单；公网防火墙与 DNS 由现有配置管理。
- README 独立列出安装、卸载、地址查询、域名开关和凭据命令，以及星枢临时 IP 恢复入口的区别。默认 HTTPS；已安装实例通过正规后台更新。
- 保留 0.9.1 的套餐权限同步、有效人数名额、原订阅续费、流量统计和历史记录功能。
