# 星枢用户中心 0.5.0

- 客户端教程改为数据库持久化，主管理员或拥有“客户端教程编辑”权限的副管理员可以编辑标题、说明、平台、客户端条目、导入步骤、HTTPS 链接和常见问题，支持条目排序与移除。保存使用版本校验，避免覆盖其他管理员的修改。
- 轻享、日常畅连及其他类别统一使用同一个套餐组件，统一卡片结构、字体、边框、信息行和按钮位置。推荐套餐保留小标签，使用相同卡片底色；移动端按单列换行展示。
- 修复机器人权限页将管理员接口对象误当数组的问题，核款管理员下拉框可以正常选择。独立轮询机器人支持红包和支付宝/微信静态收款码核验：红包需实际领取后二次确认；静态码需回复真实流水、实收金额和北京时间，再二次确认。复用同一事务核款与订单开通队列，防止重复开通。
- 修复 Telegram 过期回调确认导致轮询游标不能推进的问题；确认凭据绑定机器人、私聊用户、后台管理员、付款版本，有效 5 分钟，静态码凭据写入后不可被后续回复静默覆盖。
- 支持删除副管理员与购买用户。删除账户立即注销登录、作废邮箱令牌；删除用户排队撤销全部代理身份，删除管理员会立即使其绑定的机器人审批失效。正常列表隐藏已删除账户，已删除列表可恢复；已验证账户恢复为停用状态，未验证账户恢复后重新验证邮箱。订单、付款与核账记录保留。
- 用户删除需要额外的“删除 / 恢复购买用户”权限及用户管理权限，主管理员可用全部功能。不能删除主管理员或自己。修复权限变更任务的并发覆盖问题，使用独立任务租约代数防止旧工作进程覆盖新任务。

验证包含 PostgreSQL 业务与迁移回归、机器人轮询→回复真实流水→二次确认→独立订阅开通的隔离模拟流程、过期与权限校验、Go race/vet、16 项前端交互、生产构建与 Linux Docker 安装/回滚/卸载验收。没有替用户领取红包、审核真实付款或删除线上账户。
